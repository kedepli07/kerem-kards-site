# Kerem Kards site

Source for https://kerem-kards.netlify.app. Netlify deploys every push to `main` (publish directory: repo root, no build command).

- `index.html` sales page with the Netlify `order` form, `thanks/` after-order page
- `<client-slug>/` one page per client, made by `nfc-cards/tools/new_client.py`
- `template/` blank client page
